# 📚 Library App

Une **application web de bibliothèque numérique** construite avec **React.js** qui permet de parcourir, filtrer et rechercher des livres en ligne.  

---

## 📌 Description

Cette application récupère des livres via l’**API Google Books** et les affiche sous forme de **cartes interactives**.  
Les utilisateurs peuvent :  
- Parcourir les livres récents ou populaires  
- Filtrer par **catégorie**  
- Rechercher un livre par **titre**  
- Consulter des informations détaillées sur chaque livre via un **modal**  

L’interface est responsive et intuitive, avec une **barre de navigation** pour la recherche et le filtrage.

---

## 🛠️ Technologies utilisées

- **React.js** – Bibliothèque JavaScript pour construire l’interface utilisateur  
- **HTML5 & CSS3** – Structure et styles visuels  
- **JavaScript (ES6+)** – Logique des composants et interaction  
- **Bootstrap 5** – Composants UI et responsive design  
- **Google Books API** – Source des données des livres
